# IMP
IMP (Informative Micro Pet) is just a little guy.

---

## Desired Features
Computer vision of some sort
AI (explanations, searching, mood or something along those lines)
Gyroscope
Head itself is a button
Battery (~8 hours of battery life) with UPS function
Accelerometer
Under 200g
Fits in palm
(Maybe some more...)

## Current Components
NFP1315-45A - OLED Display
ESP32 DevKit v1 Type-C
